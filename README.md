# 🩸 Blood Bank Management System

A desktop-based **Blood Bank Management System** developed using **Java Swing, Object-Oriented Programming (OOP), and File Handling**. It provides a graphical interface to manage blood donors, recipients, and blood product inventory.

## ✨ Features

* 🔐 **User Authentication:** Login, registration, and duplicate username checking
* 🧑‍🩸 **Donor Management:** Add, update, search, delete, and view donor records
* 🏥 **Recipient Management:** Manage blood recipients and their requirements
* 📦 **Inventory Management:** Track blood products, quantities, and expiry dates
* 💾 **File Handling:** Store and retrieve data using text files
* 🖥️ **GUI:** Interactive interface built with Java Swing

## 🛠️ Technologies Used

* Java (Java SE)
* Java Swing & AWT
* Object-Oriented Programming (OOP)
* File Handling (Java I/O)
* Arrays
* Git & GitHub

## 📂 Project Structure

```text
Blood Bank/
├── Backup/       # Images and resources
├── Entity/       # Data model classes
├── EntityList/   # Array-based data management
├── File/         # File I/O and data files
├── GUI/          # Application interfaces
└── Start.java    # Entry point
```

## ⚙️ Installation & Setup

**Prerequisite:** Install the Java Development Kit (JDK).

1. Clone the repository:

   ```bash
   git clone https://github.com/Asfaq5459/Blood-Bank-Project-Java.git
   ```

2. Open the project in a Java-compatible IDE such as IntelliJ IDEA, Eclipse, or NetBeans.

3. Run `Start.java` from the project root directory.

The application opens with the login page. Register an account to get started.
